## 🚀 Getting Started

### Prerequisites
- Node.js 18+ or later
- npm or yarn / pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/monammunir/Bios-Medical.git

# Navigate to project folder
cd Bios-Medical

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build

```bash
npm run build
npm run preview
```

- **Framework**: React 19 + TypeScript

- **Styling**: Tailwind CSS v4
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Deployment**: Vercel
